# AGENTS.md: src/main/

What this folder's files are. Read the root [AGENTS.md](../../AGENTS.md) first: the commands, the architecture, the invariants, the conventions.

## Files

| file | what |
|---|---|
| `src/main/index.ts` | Electron main (every IPC handler checks its sender: `fromApp`, the token's; `from(e, …pages)`: the app window, else only the pages named, `new`, `ai`, `tab` by `?window=`, `voice` the bubbles'; the bubbles', the editor's and a floated tab's own by their window): single instance, starts the daemon, window (where it was left: `window.json` in userData, `winAt`, bounds, maximized, full screen; else maximized; hiddenInset title bar; traffic lights centered in the 38px header; `glass` IPC: vibrancy and a clear background, the window `transparent` on a Mac for it), the app menu and the menu bar item (`menu.ts`; *Quit Laki Completely*: `quitCompletely`, `shutdown`, asking first when an agent is running; a Browsers page's `before-input-event` takes `newTab`/`closeTab`'s keys by `keyFor`), notifications and cards on screen (`cards.ts`), the agent browser (`agentBrowser.ts`), screenshots (`shots.ts`; the menu bar's *Show and Tell…*: `tellShot`, the quick bar with the picture and the mic on, Q7), the floating bubbles (`floater.ts`), `pick-folder` IPC, `open-external` (http(s) and mailto only), laki:// links, the preview's webview guard |
| `src/main/floater.ts` | the floating bubbles (`floats` IPC: `placeFloater`, floater.html's bar and the card, menu and voice windows it opens; `floater-act`, `voice-send`), the island at the notch, the pinned circle, drops on the bar, the talk key's pill (Q2: `talk`, its dictation), whether Laki is in front (`setFront`), Fn's watch; each handler checks its window. It and index.ts import each other: nothing at its top level reads index.ts' bindings as it loads (its own `mac`), as the bundle runs it first |
| `src/main/shots.ts` | screenshots: the menu bar's (`screenshot`: macOS's screencapture, a part or a screen, the bubbles out of it: `shooting`; `screenPick`), the editor window to draw on one (`annotate`, `annotate-done`), a part for a prompt (`shoot`), the preview's and a page's (`capture`, `page-shot`, `wholePage`, `capture-rect`); index.ts' `sendShot` gives the window its picture |
| `src/main/cards.ts` | notifications and cards on screen: `notify` (its buttons answer through the daemon), the cards for what's marked important (`addCard`: ask.html at the bottom right, over every app), the menu bar's Inbox (`inboxSet` with each badge, `inboxOpen`), `ask-act`, `ask-explain`, Open, ×, Close all, `asking`, a timer's sound; each handler checks its sender |
| `src/main/agentBrowser.ts` | the agent browser (`browse` IPC: the app window's, the daemon's call through it): a hidden window per tab, `AGENT_TABS` per workspace, in the preview's session (this Mac's localhost), gone after 10 idle minutes; each op through the Chrome DevTools Protocol, with the errors, blocked loads and changes it caused |
| `src/main/menu.ts` | the menus: a native popup for the renderer's (`menu-popup`, Settings › Layout's Menus: macOS), the menu bar's item (`Tray`, its picture by state, Q8: `shared/tray.ts`; its menu, drops on it, Quiet), the `badge` IPC that feeds it and the Inbox, Hand off, the Dock's icon, count, progress, menu and recent folders, the app menu (with *Quit Laki Completely*; File, Edit, View and Go list the renderer's ⌘ keys: `key()`, `registerAccelerator: false`, a click sends `browser-key`; Settings › Keys' through `bound()`, from the `keys` IPC's `keysNow`; `appMenu` builds it again, index.ts calls it once everything is defined) |
| `src/main/smoke.ts` | `npm run test:ui` and `test:sheet` (`--laki-smoke=<dir>`, `uiSmoke`): the real window walked page by page, then the risky flows (E3), each step waited for and screenshotted, `sheetDiff` against the last run's; index.ts starts it once the window has loaded |
| `src/main/guards.ts` | main's checks, pure (no electron: `test/main-guards.test.ts`): who sent an IPC message (`fromApp`, `pageIs`), and the URLs it lets through (`local`, `web`, `webviewOk`, `externalOf`), the partitions' names; `titleOf` (shared/title.ts: a window's title, cleaned, for `win-title`) |
| `src/main/back.ts` | #G1: Go back: the version before an update kept (ditto to userData/previous.noindex: out of Spotlight), checked (codesign, Team ID) and swapped in, then a relaunch |
| `src/main/update.ts` | the app's updates: GitHub's latest release, Squirrel.Mac's download and install, an AppImage's own (Updates: `docs/dev/scans.md`) |
| `src/main/appimage.ts` | Linux self-update, no electron: the release's AppImage beside `$APPIMAGE`, checked against its SHA256SUMS.txt, swapped in by rename (one `.previous` kept for Go back) |
